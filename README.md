# 臺灣小小探險家與社會填空閃卡

依翰林版國小五年級上學期社會第一、第二單元整理的網頁練習工具。

## 功能

- 地圖探險：19 個站點、57 道選擇題、逐站解鎖與圖鑑收集。
- 填空閃卡：224 題、306 個填空，每次一題，點按揭曉答案。
- 可依單元、主題、熟悉度篩選，選擇每回合張數與隨機出題。
- 支援手機畫面，學習紀錄以 localStorage 保存在目前瀏覽器。

## 本機執行

先安裝 Node.js 18 或更新版本，不需安裝額外套件。

```sh
npm run dev
```

開啟以下網址：

- 地圖遊戲：http://127.0.0.1:4173/
- 填空閃卡：http://127.0.0.1:4173/flashcards/

## 檢查

```sh
npm test
```

檢查題數、填空數、答案顯示、熟悉度紀錄、題庫篩選、回合完成與儲存狀態。

## 專案結構

```text
dist/
  index.html          地圖遊戲入口
  app.js              地圖遊戲互動
  data.js             地圖遊戲題庫
  flashcards/
    index.html        填空閃卡入口
    app.js            閃卡互動與學習紀錄
    questions.js      224 題完整題庫
    style.css         手機與桌面版樣式
preview.cjs           本機預覽伺服器
check-flashcards.cjs   閃卡功能檢查
```

## 靜態部署

將 `dist/` 目錄部署到支援靜態網站的服務即可，不需要建置或資料庫。
Sites 的部署設定位於 `.openai/hosting.json`；使用其他服務時不需此設定。
